### 项目简介

- 基于 React 18 + TypeScript + WebAssembly + Web Worker 技术构建的高性能在线图像编辑器，提供接近原生应用的处理速度和流畅的用户体验。通过 Web Worker + OffscreenCanvas + OpenCV.js（WebAssembly）将图像处理彻底从主线程解耦，确保 UI 的持续响应性。提供实时裁剪/旋转/翻转、水印（文字/图片）、亮度/对比度/模糊等效果，以及多图拼贴与导出预览。设计并实现历史系统，支持撤销/重做，且区分“预览/应用”两阶段，避免卡顿与脏历史。

- 技术栈：React 18、TypeScript、Vite、Zustand、Ant Design、Tailwind CSS、Web Worker、OffscreenCanvas、OpenCV.js（WebAssembly）、createImageBitmap、Vitest + React Testing Library、ESLint/Prettier/Husky/lint-staged。

### 主要工作

- **架构设计与性能治理**
  - 设计“Worker + OffscreenCanvas + OpenCV.js”流水线，定义 `opencv-loaded`/`worker-ready` 握手与 `transferControlToOffscreen` 的幂等初始化，保证只转移一次控制权。
  - 混合处理引擎：智能选择 JavaScript 或 WebAssembly 引擎；简单滤镜（sepia/grayscale/brightness/contrast/watermark）使用 JS，复杂算法（blur/sharpen/canny/threshold/crop/rotate/flip/faceBeauty）使用 WASM。
  - 引入 `PerformanceTimer` 全链路分步计时（解码/计算/绘制），在 Worker 侧输出结构化性能日志，定位瓶颈与回归。
  - 首屏按路由/功能懒加载：`ParamsPanel`、`ExportPanel`、`CollageMode` 通过 `React.lazy` 拆分，减少初始包体。
  - 性能指标（4K 图像 3840×2160）：简单操作（灰度/亮度/对比度/复古等）单次响应 ≤ 200ms；复杂操作（高斯模糊/锐化/边缘检测/阈值/裁剪/旋转/翻转等）单次响应 ≤ 500ms；OffscreenCanvas 保证交互稳定 60fps。

- **核心功能与交互体验**
  - 历史系统：`HistoryManager` 深拷贝入栈、有界历史、撤销/重做/索引跳转；“预览不入栈、应用才入栈”，并用 `lastProcessedImageId` 防重复渲染。
  - 裁剪交互：覆盖层 `cropCanvas` 实时描绘矩形，与主 Canvas 缩放/平移对齐，安全裁剪参数校验。
  - 拼贴：`imageCollageUtils` 支持水平/垂直/网格布局（间距/列数/背景色），预览与应用分离，应用后进入主编辑流程。
  - 导出：`createImageBitmap` 高效缩放 + `compressCanvasImage`（JPEG/PNG/WebP）即时大小预估；关闭面板回收 `Blob URL`。

- **工程化与可维护性**
  - 状态分层：Zustand 拆分 `editorStore`/`imageStore`/`uiStore`/`collageStore`，处理态/工具态/UI 态解耦；`useZoom` + `ResizeObserver` 做适屏缩放并与用户手动缩放解耦。
  - 通知体系与类型规范：`notificationService` 解耦 App 实例；公开 API 显式类型；Worker 消息/图像数据/导出参数统一于 `types/index.ts`。

- **测试与质量保障**
  - 质量门禁：TypeScript 严格模式、ESLint + Prettier、Husky + lint-staged（类型检查/相关测试）。
  - 测试体系与指标：单元测试 + 集成测试双层保障（Vitest + React Testing Library），测试环境下 mock OffscreenCanvas/Worker/ImageData；覆盖率目标：整体覆盖率 ≥ 50%，单元测试覆盖率 ≥ 90%。
