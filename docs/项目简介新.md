### 项目简介

- 基于 React 18 + TypeScript 的浏览器端高性能图像编辑器。通过 Web Worker + OffscreenCanvas + OpenCV.js（WebAssembly）将重型图像处理彻底从主线程解耦，提供实时灰度/复古/亮度/对比度/模糊/锐化/边缘/阈值/增强、裁剪/旋转/翻转、水印（文字/图片）、人像背景去除与“美颜”效果，以及多图拼贴与导出预览。
- 技术栈：React 18、TypeScript、Vite、Zustand、Ant Design、Tailwind CSS、Web Worker、OffscreenCanvas、OpenCV.js（CDN 加载 Wasm）、createImageBitmap、Vitest + RTL、ESLint/Prettier/Husky/lint-staged。
- 架构要点：混合处理引擎（JS/Wasm 智能择优），主线程仅负责交互与调度；处理结果在 Worker 侧 OffscreenCanvas 绘制并回传性能日志；历史系统支持撤销/重做且区分“预览/应用”两阶段，避免卡顿与脏历史。

### 主要工作

- **架构与性能**
  - 设计“Worker + OffscreenCanvas + OpenCV.js”流水线，定义 `opencv-loaded`/`worker-ready` 握手与 `transferControlToOffscreen` 的幂等初始化，保证只转移一次控制权。
  - 实现混合引擎：复古/灰度/亮度/对比度/水印走高效 JS；裁剪/旋转/翻转/模糊/锐化/边缘/阈值/增强/背景去除/美颜走 Wasm（OpenCV.js）；OpenCV 未就绪自动 JS 降级。
  - 引入 `PerformanceTimer` 全链路分步计时（解码/计算/绘制），在 Worker 侧输出结构化性能日志，定位瓶颈与回归。

- **复杂逻辑与稳定性**
  - “美颜”实现：人脸区域估算 + 双边滤波磨皮 + 自然提亮 + 羽化蒙版融合；异常降级至纯 JS，保障边缘自然与稳定性。
  - 背景去除：基于 GrabCut 与透明度通道处理，逐像素抠图并保留 Alpha。
  - 严格内存管理：所有 `cv.Mat`/`MatVector`/kernel 置于 try/finally 显式 `delete()`，规避长会话泄漏；`toStandardImageData` 兼容 SharedArrayBuffer。

- **编辑体验与历史系统**
  - 设计 `HistoryManager`（深拷贝入栈、有界历史、Redo/Undo、索引跳转），与 `imageStore` 的 `setImage/updateImage/undo/redo` 解耦；“预览不入栈、应用才入栈”，并用 `lastProcessedImageId` 去重处理。
  - 裁剪交互：覆盖层 `cropCanvas` 实时描绘矩形，与主 Canvas 缩放/平移对齐，同步安全裁剪参数校验。

- **拼贴与导出**
  - 多图拼贴：水平/垂直/网格布局与尺寸预估，支持间距/列数/背景色，预览与应用分离。
  - 导出预览：`createImageBitmap` 高效缩放 + `compressCanvasImage`（JPEG/PNG/WebP）即时文件大小预估；关闭面板时回收 `Blob URL`。

- **工程与质量**
  - Zustand 模块化状态：`editorStore`（Worker/OpenCV/工具态/视图）、`imageStore`（图像与历史）、`uiStore`（加载/导出/特性检测）、`collageStore`（拼贴）。
  - 自动化质量门禁：TypeScript 严格模式、ESLint + Prettier、Husky + lint-staged（类型检查/相关测试）；Vitest + RTL 覆盖关键链路（Canvas、useImageProcessing、历史与 store），配合覆盖率改进计划。
  - 统一通知与确认：封装 `notificationService` 与 AntD `App` 实例，保证一致的交互反馈。

- **面试可深入话题**
  - Worker/Wasm 混合引擎取舍与消息协议；OffscreenCanvas 控制权转移的时序/幂等。
  - OpenCV.js Wasm 远程加载策略与内存生命周期管理；大图处理的性能/内存权衡。
  - 历史栈一致性（预览/应用分流）与去重渲染；导出预览的高性能实现与资源回收。
  - 降级与容错（JS ↔ Wasm、异常兜底与 UI 恢复）。

- **代表实现**
  - `src/utils/imageWorker.ts`（Wasm/Worker 处理管线、性能日志、降级）
  - `src/hooks/useImageProcessing.ts`（编辑指令编排与消息处理）
  - `src/utils/historyManager.ts`（撤销/重做/有界历史/跳转）
  - `src/store/*`（editor/image/ui/collage 模块化状态）
  - `src/components/layout/Canvas.tsx`（Worker 初始化、original 通道、裁剪交互）

- **完成内容与亮点**
  - 混合引擎与 OffscreenCanvas 让 UI 始终流畅。
  - 美颜与背景去除在浏览器端可用且可回退。
  - 有界历史与预览/应用分流，保证性能与可撤销性。
  - 完整工程化与测试基建，支持持续演进。

- **简要总结**
  - 搭建了可扩展、高性能、工程质量可控的 Wasm 图像编辑器；在性能、稳定性与 DX 之间达成平衡，为后续 WebGPU/AI 滤镜等扩展预留空间。
